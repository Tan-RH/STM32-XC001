## 基础指令

|指令|参数|说明|
|--|--|--|
|`*IDN?`||查询设备身份信息|
|`*CLS`||清除状态和错误队列|
|`*RST`||复位设备或业务模块|
|`PING?`||通信链路测试|

### 示例

```scpi
*IDN?      # 查询设备身份
PING?      # 通信测试
```

### 返回示例

```text
<制造商>,<型号>,<序列号>,<固件版本>
PONG
```

## 系统指令

|指令|参数|说明|
|--|--|--|
|`SYST:ERR?`||查询系统错误状态|
|`SYST:HELP?`||查询当前固件支持的 SCPI 指令列表|

### 系统错误返回值

|返回值|说明|
|--|--|
|`0,"No error"`|当前无错误|
|`ERR,-100,"Empty command"`|空指令|
|`ERR,-109,"Missing parameter"`|缺少参数|
|`ERR,-113,"Undefined header"`|未知指令|
|`ERR,-222,"Invalid ..."`|参数非法或操作失败|
